Go lang is comparable with pure Java. But this is different language for diffrent goal . It is more sililar to C for application, you have pointers but usage is limited. I very like defer statement . 


package main

import (
	"fmt"
	"os"
)

var file *os.File

func closeFile(file *os.File) {
	file.WriteString(" last line\n")
	file.Close()
	fmt.Println(" file closed ")
}

func main() {
	var err error
	file, err := os.OpenFile("raii_global.txt", os.O_CREATE, 0666)
	if err != nil {
		panic(err)
	}
	defer closeFile(file)
	file.WriteString(" start ====> \n ")
	file.WriteString(" the next line\n")
}

However, there are a pitfall like in C: you should not forget to set os.O_TRUNC, similar to “w+” in C. Go’s style is like POSIX, but not all flags are the same.

Truncate means delete old content and write a new one. Try youself write into file without it like in example bellow. 


##include <unistd.h>
#include <fcntl.h>
#include <cstdio>
#include <iostream>
#include <string>
#include  "../Color.hpp"

int main() {
    const int fd = open("../bin/example.txt",
                   O_WRONLY | O_CREAT | O_TRUNC);
    if (fd == -1) {
        perror("open");
        std::cout << "\033[31m" << " error " << "\033[0m\n ";
        return 1;
    }

    const std::string msg = "Hello from POSIX-style Linux!\n";
    write(fd, msg.data(), msg.size());

    close(fd);
    const std::string successMsg=  "File written successfully!\n";
    std::cout <<  Color::apply(Color::FG::Magenta, Color::BG::Black,  successMsg);
    return 0;
}

However Go lang is C-Style language , this means is not OOP modern C++ is use cross platform library 


#include <filesystem>
#include <fstream>
#include <iostream>
#include <string>
#include  "../Color.hpp"

int main() {

    std::ofstream file("../bin/example.txt", std::ios::in | std::ios::trunc);
    if (!file) {
        std::cout <<  Color::apply(Color::FG::Red, "can't open file ");
        return -1;
    }
    const std::string content = "Hello\nThis is saved to a file.";
    file << content;
    std::cout <<  Color::apply(Color::FG::Magenta, Color::BG::Black,  " File written successfully  ");
    return 0;
}

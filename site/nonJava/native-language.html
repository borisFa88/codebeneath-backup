Programming Languages

There are many different programming languages, most of which are highly effective for building applications. Languages like Java and C# remain the primary choices for developing enterprise-level applications. Then there is Go (Golang), which is an excellent tool for building high-performance microservices and small servers. Python is also within this scope, though as a scripting language, it deserves its own dedicated discussion.

This section introduces you to native code, focusing primarily on C and C++. While other languages like Rust, D, and Zig also play significant roles in the native ecosystem, we will focus on the industry standards due to their widespread adoption and performance capabilities.


#include <stdio.h>
#include <signal.h> 
#include <stdlib.h>
#include <stdio.h>
#include <signal.h>
#include <unistd.h>

#define CYAN "\033[33m"
#define BLUE "\033[36m"
#define RESET "\033[0m"

volatile sig_atomic_t should_exit = 0;
void handle_sigint(int sig) {
    printf("\nCaught signal %d (SIGINT). Exiting safely...\n", sig);
    should_exit = 1;
}

int main(void) {
    // Register signal handler
    signal(SIGINT, handle_sigint);

    printf(CYAN "Running... Press Ctrl+C to send SIGINT\n");
      
    while (!should_exit) {
        printf(BLUE " Working ..." RESET  "\n");
       // printf("Working...\n");
        sleep(1);
    }

    printf( CYAN "Exiting cleanly\n");
    return 0;
}

C and C++ are low-level languages that serve as the foundation for almost all modern software. While higher-level languages wrap this core logic in layers of abstraction to simplify development, understanding the underlying native code is invaluable.





A defining feature of low-level programming is manual memory management. Unlike most modern languages that hide pointers and automate memory handling to increase safety, C++ allows the developer to interact with memory directly through pointers. This gives the programmer both the power and the responsibility to allocate and release memory manually, ensuring maximum efficiency and performance.





















 
#include <stdio.h>
#include <stdlib.h>

int main() {
  // Allocate memory for a number of items
  int numItems = 15;
  int *myArray = malloc(numItems * sizeof(int));

  // Display the contents of the memory
  for(int i = 0; i < numItems; i++) {
    printf("%d ", myArray[i]);
  }

  // Free the memory
  free(myArray);  
  return 0;
}







Unlike many modern languages, C++ does not have a built-in Garbage Collector. As a programmer, you are solely responsible for both allocating and releasing memory.





While languages like Java and C# use Garbage Collection to automate this process and prevent errors, C++ takes a different approach. In those 'managed' languages, the system handles memory safety behind the scenes, often hiding pointers from the developer. In C++, you work directly with memory addresses. While this presents a significant challenge, it also provides the ultimate control and performance required for high-speed, native applications.





However C++ comparing C allows you to write safety code on other side and also allows you to write in C-style using pointers. And you can choose which style is better for you. Example for safety code is RAII mechanism , resource acquisition, see example 











 
#include <string>
#include <cstdio>
#include <cstring>
#include <iostream>
class LinuxDistroDetector {
public:
    LinuxDistroDetector() : osFile(nullptr) {
        #if !defined(__linux__)
                throw std::runtime_error(" this is not linux machine ");

        #endif
    } ;

    ~LinuxDistroDetector() {
        std::cout << "\033[34m close file descriptor \033[0m\n";
        fclose(osFile);
    }

    [[nodiscard]]
    std::string detect();

private:
    const char* path="/etc/os-release";
    const char* mode="r";
    FILE *osFile;
    [[nodiscard]]
    std::string read_os_release()  {
       osFile = fopen(path, mode);
        if (!osFile)
            return {};
        char line[256];

        while (fgets(line, sizeof(line), osFile)) {
            if (std::strncmp(line, "PRETTY_NAME=", 12) == 0) {
                std::string data(line);
                const size_t iStart= data.find('"');
                if (iStart == std::string::npos ) {
                    continue;
                }
                const std::size_t  iEnd = data.find('"',iStart);
                if (iEnd == std::string::npos) {
                    continue;
                }
                 return data.substr(iStart+1,iEnd-iStart-1);
            }
        }
        return {};
    }
};

std::string LinuxDistroDetector::detect() {

    if (auto name = read_os_release(); !name.empty())
        return name;
    return "Unknown Linux Distribution";
}

int main() {
    LinuxDistroDetector detector;
    std::cout << "\033[33m " <<  detector.detect() << "\033[0m";
}

How to Read an Unknown HTTP Request Body Type

Written by

Boris Fain

in

HTTP Requests
Spring is very power framework and allows to read and convert client data with differrent type using annotations. On your controller you should declate a method and set you consumer like is shown on example bellow. 

And Person class 

@JacksonXmlRootElement(localName = "Person")
public class Person {
    private String name;
    private int age;
}


Finally you should add JacksonXmlRootElement dependecy to pom.xml


<dependency>
    <groupId>com.fasterxml.jackson.dataformat</groupId>
    <artifactId>jackson-dataformat-xml</artifactId>
</dependency>


Start server and run 


curl -X POST serverAddress:port/api/person -H "Content-Type: application/xml" -d 'John30'


Spring know how to parse you xml because you are using annotation ,
but what to do if you type is not xml, but it is json, or image, or audio ? or you want to send it dynamically ?
Threre are only few examples for valid type :

text/plain, text/csv, application/json , application/pdf , image/pgn , image/gif , audi/mpeg audio/wave, video/mp4 , video/mpeg

And each type has a different implementation
Code example is here https://github.com/borisFa88/HttpDynamicRequest
There are two ineresting points here the first is content type
line 34 String contentType= request.getContentType();
String framework privides this method but more proper way is to use header
String contentType= request.getHeader(“content-type”);
In most frameworks , this is the sole way to accomplish it.
Once you know content type you know how to read and parse request
The second step if fill map contains content type as a key and handler.
For a specific content type , you should implement a dedicated content type.
Content type should be different below there are offical 9 groups also named application audio font example image message model multipart text video and client can sent it like application/zip or font/woff , image/gif, message/rfc822

And you can create you custom type for you specific goal writing Content-Type: customGroup/typeA” and on server side you will get after request.getContentType() or request.getHeader(“contentType”) if you use not Spring framework.

And finally you need to put implementation in any folder, httpHandlers in my example, folder and method setAllTypeHandlers as part of class ServiceDispatcher saved in the map, and getService method return it , because it single tone it filled only once. This code could updated by few ways but the pattern is the same.

curl -X POST http://localhost:8000/anyTypeClient -H “Content-Type: app/custom” -d ‘value
30′
